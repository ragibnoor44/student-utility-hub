About This Project

Secure Student Utility Hub is an all-in-one student productivity dashboard that brings notes, tasks, and security-first design together in one place.

This project Started with HTML and CSS, and is gradually evolving with JavaScript, Bootstrap, React, and a Node.js/MongoDB backend. Each Stage has added a new feature, with security best practices - such as input validation and authentication - kept as a core priority throughout.

Teck stack Used
  • HTML5 & CSS3
  • Bootstrap 5
  • JavaScript (Vanilla)
  • React
  • Node.js
  • MongoDB
